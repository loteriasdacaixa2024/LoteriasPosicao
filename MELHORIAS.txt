# Nova funcionalidade

Criar uma nova aba na mesma rota:

## Pool de Dezenas (01-31) Especial

Objetivo:

Criar uma forma de carregar automaticamente pools estratégicos de dezenas para utilizar o mesmo construtor já existente da aba:

## Pool de Dezenas (01-31)

A nova aba NÃO deverá criar um novo gerador.

Ela deverá apenas:

1. Permitir escolher uma distribuição.
2. Carregar as 16 dezenas da distribuição escolhida.
3. Enviar essas dezenas para o mesmo fluxo de construção já existente.

Fluxo esperado:

```
Escolher Distribuição
        ↓
Carregar Pool com 16 dezenas
        ↓
Utilizar motor atual de construção
        ↓
Gerar construções
```

---

# Regra principal

Todas as distribuições obrigatoriamente terão:

## TOTAL = 16 DEZENAS

Essa regra é fixa.

O sistema deverá validar que qualquer distribuição cadastrada tenha exatamente 16 dezenas.

Nunca permitir:

* menos de 16;
* mais de 16;
* distribuição incompleta.
